# ProductSuiteApp

Aplicación contenedora del portfolio `iOS Product Engineering`.  
Integra todos los módulos técnicos y frameworks para visualizar el sistema en acción.

---

## Propósito

Servir como punto de entrada para explorar el sistema completo:  
- Navegación entre módulos
- Integración visual unificada
- Ejecución de flujos demostrativos

---

## Contenido

- Dashboard de módulos (MotionStudio, ArchitectureBench, UXBlueprints, etc.)
- Demostraciones integradas
- Ejemplo de composición modular escalable

---

## Arquitectura

- **SwiftUI** para composición visual
- **Clean Architecture** para separación de responsabilidades
- **Dependency Injection** vía constructor
- **Modularización** estricta usando Swift Package Manager

---

## Requisitos

- iOS 17+
- Xcode 15+
